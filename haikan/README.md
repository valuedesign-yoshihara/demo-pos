# 拝観受付レジ WUXGA 10.1インチ 大きめ版

10.1インチ WUXGA（1,920×1,200）クラスのAndroidタブレット横向き利用を想定した、寺院の拝観受付向けレジ画面サンプルです。

既存のWUXGA版よりも、文字・ボタン・テンキー・履歴操作をさらに大きくし、シルバー人材の方など高齢の担当者でも見やすく押しやすいサイズ感に調整しています。

## 試す方法

`index.html` をブラウザで開くと動作します。Webサーバー上に置くと、Androidのホーム画面追加やオフラインキャッシュのサンプルも確認できます。

## 入っている主な操作

- 通常拝観、特別拝観、割引・団体のタブ切替
- 大人、小人、学生、障がい者、介助者、幼児などの人数選択
- よく使う人数プリセットと各券種の `+5`
- 選択内容、人数、数量、合計の常時表示
- 現金決済の預り金、お釣り表示
- キャッシュレス種別選択と承認確認
- 直前取消、全取消、会計履歴と取消

料金や券種は `app.js` の `menuData` を変更すると調整できます。
